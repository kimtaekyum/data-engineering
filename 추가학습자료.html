시험 2장: NumPy 배열

실습 01

핵심 개념 5개

  • NumPy 배열은 같은 연산을 여러 원소에 한 번에 적용할 수 있다.
  • 인덱싱과 슬라이싱으로 배열 일부를 선택한다.
  • 불리언 마스크는 조건에 맞는 원소만 선택한다.
  • 슬라이싱 결과는 원본의 view가 될 수 있다.
  • reshape, concatenate, vstack, hstack으로 배열 구조를 바꾼다.

대표 코드

np.array([1, 2, 3])
arr[2:8:2]
arr[arr >= 10]
arr[:2, :2].copy()
x.reshape(2, 5)

헷갈리는 포인트

view는 원본 메모리를 공유하고, copy는 별도 복사본을 만든다. 원본 변경 여부를 항상 의식해야 한다.

시험 3장: NumPy 연산과 고급 기능

실습 02, 03

핵심 개념 5개

  • NumPy 벡터화 연산은 Python loop보다 대량 계산에 유리하다.

대표 코드

1 / big_array

np.add.accumulate(x)

헷갈리는 포인트

axis=0은 열별 결과, axis=1은 행별 결과로 이해하면 빠르다. 브로드캐스팅은 오른쪽 차원부터 비교한다.

시험 7장: 시계열 데이터

실습 10, 11

핵심 개념 5개

  • 문자열 날짜는 datetime으로 변환해야 시간 연산이 가능하다.
  • strftime은 datetime을 문자열 형식으로 출력한다.
  • 시계열 인덱스는 시간 기준 선택과 집계에 중요하다.

시험 8장: 결측치 처리와 대치

실습 12, 13

핵심 개념 5개

시험 9장: 이상치 탐지

실습 14

핵심 개념 5개

  • 이상치는 정상적인 패턴에서 크게 벗어난 값이다.
  • IQR은 Q3와 Q1의 차이다.
  • IQR 기준은 Q1 - 1.5*IQR, Q3 + 1.5*IQR를 사용한다.

  • 이상치는 평균, 분산, 모델 성능을 왜곡할 수 있다.

대표 코드

q1 = df['x'].quantile(0.25)
q3 = df['x'].quantile(0.75)
iqr = q3 - q1
z = (x - x.mean()) / x.std()
df[np.abs(z) > 3]

헷갈리는 포인트

결측치는 값이 없는 상태이고, 이상치는 값은 있지만 비정상적으로 벗어난 상태다.

예시 답안 1. concat과 merge

concat은 여러 데이터 객체를 행 또는 열 방향으로 이어 붙이는 기능이고, merge는 공통 키를 기준으로 테이블을 결합하는 기능이다. concat은 축 방향 연결이 핵심이고, merge는 관계형 데이터베이스의 join처럼 키 매칭이 핵심이다. 예를 들어 월별로 같은 구조의 매출 데이터를 쌓을 때는 concat이 적절하고, 회원 정보와 주문 로그를 UserID로 연결할 때는 merge가 적절하다. 데이터 엔지니어링 관점에서는 결합 방식 선택이 데이터 누락, 중복, NaN 발생 여부에 직접 영향을 준다.

예시 답안 2. API와 웹스크래핑

API는 서비스가 제공하는 정해진 인터페이스를 통해 구조화된 데이터를 요청하는 방식이고, 웹스크래핑은 HTML 문서에서 필요한 데이터를 직접 추출하는 방식이다. API는 URL과 파라미터를 이용해 JSON 같은 형태로 데이터를 받는 반면, 웹스크래핑은 HTML 태그와 선택자를 분석해야 한다. 예를 들어 CoinGecko API에서는 코인 가격 데이터를 JSON으로 받을 수 있고, 뉴스 페이지에서는 BeautifulSoup으로 제목 태그를 찾아야 한다. 데이터 엔지니어링 관점에서는 API가 더 안정적이지만 rate limit과 인증을 고려해야 하고, 웹스크래핑은 구조 변경과 사이트 정책을 고려해야 한다.

Python loop vs NumPy ufunc Python loop는 원소를 하나씩 처리하고, ufunc는 배열 전체에 벡터화 연산을 적용한다. 속도, 대량 데이터, 벡터화, C 기반 최적화
view vs copy view는 원본 메모리를 공유하고, copy는 별도 데이터를 만든다. 원본 변경, 메모리 공유, 슬라이싱
loc vs iloc loc는 라벨 기준이고, iloc는 정수 위치 기준이다. 명시적 인덱스, 암묵적 인덱스, 끝 포함 여부
Series vs DataFrame Series는 1차원 라벨 배열이고, DataFrame은 2차원 표 형태 객체다. 1차원, 2차원, 컬럼, 인덱스
concat vs merge concat은 축 방향 연결이고, merge는 공통 키 기준 결합이다. 축, 키, join, 관계형 결합
inner join vs left join vs outer join inner는 교집합, left는 왼쪽 보존, outer는 양쪽 전체 보존이다. 교집합, 기준 테이블, NaN, 매칭 실패
결측치 vs 이상치 결측치는 값이 없는 상태이고, 이상치는 값은 있지만 정상 범위를 벗어난 상태다. NaN, 누락, 비정상 값, 품질 점검
웹스크래핑 vs API 웹스크래핑은 HTML에서 추출하고, API는 정해진 인터페이스로 구조화 데이터를 요청한다. HTML, JSON, 선택자, 파라미터, rate limit
문자열 날짜 vs datetime 문자열 날짜는 텍스트이고, datetime은 시간 연산이 가능한 객체다. 타입 변환, 시간 인덱스, 기간 필터링, 집계
axis=0 vs axis=1 axis=0은 행 축을 줄여 열별 결과를 만들고, axis=1은 열 축을 줄여 행별 결과를 만든다. 열별 집계, 행별 집계, 축 방향
resampling vs rolling resampling은 시간 단위를 바꿔 집계하고, rolling은 이동 창으로 통계를 계산한다. 시간 해상도, 이동 평균, 시계열 추세
결측치 제거 vs 결측치 대치 제거는 결측 행/열을 없애고, 대치는 평균이나 이전값 등으로 빈 값을 채운다. 데이터 손실, 분포 왜곡, imputation
IQR vs Z-score IQR은 사분위수 기반이고, Z-score는 평균과 표준편차 기반이다. Q1, Q3, 1.5*IQR, 표준편차, 극단값
one-hot encoding vs normalization 원핫인코딩은 범주형 변수를 숫자 컬럼으로 바꾸고, 정규화는 수치형 변수의 스케일을 맞춘다. 범주형 변환, 스케일 조정, feature engineering
