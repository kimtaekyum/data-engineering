1. 장별 핵심 개념 + 실습 코드

2장: NumPy 배열

실습 01

핵심 개념

  • NumPy 배열은 원소 단위 연산을 지원한다.
  • 슬라이싱은 원본의 view가 될 수 있다.
  • 마스크는 조건에 맞는 원소만 선택한다.
  • reshape는 원소 수가 같아야 가능하다.

왜 중요한가

대량 데이터를 반복문 없이 처리하고, 배열의 일부를 빠르게 선택하거나 구조를 바꿀 수 있다. view/copy를 모르면 원본 데이터가 의도치 않게 바뀐다.

대표 코드

arr = np.array([1, 20, 4, 6, 28])
arr[arr >= 10]
sub = arr2d[:2, :2].copy()
x.reshape(2, 5)
np.concatenate([arr_1, arr_2])
예상 서술형: NumPy 배열은 Python list와 달리 배열 전체에 같은 연산을 한 번에 적용할 수 있다. 이는 센서값 보정이나 점수 계산처럼 여러 값을 동시에 처리할 때 유용하다. 슬라이싱은 view가 될 수 있어 메모리 효율적이지만 원본 변경 위험이 있으므로 필요하면 copy()를 사용해야 한다.

3장: NumPy 연산과 고급 기능

실습 02, 03

핵심 개념

  • UFunc는 배열 원소에 빠르게 적용되는 함수다.
  • axis=0은 열별 결과, axis=1은 행별 결과다.
  • 브로드캐스팅은 오른쪽 차원부터 shape을 비교한다.
  • fancy indexing은 원하는 행/열 조합을 뽑는다.

헷갈리는 포인트

np.linspace(0, 100, 5)의 세 번째 값은 간격이 아니라 개수다. np.arange는 stop 미포함, linspace는 기본적으로 stop 포함이다.

대표 코드

x = np.arange(4)
np.add(x, 5)
np.add.accumulate(np.arange(1, 5))
np.sum(arr, axis=0)
patch = image[rows[:, np.newaxis], cols]
예상 서술형: 브로드캐스팅은 shape이 다른 배열끼리 연산할 수 있게 해주는 규칙이다. 오른쪽 차원부터 비교하여 차원이 같거나 한쪽이 1이면 연산이 가능하다. 데이터 엔지니어링에서는 대량 데이터에 보정값이나 기준값을 반복문 없이 적용할 수 있어 중요하다.

4장: Pandas 객체와 데이터 조작

실습 04, 05

핵심 개념

  • Series는 1차원 라벨 배열, DataFrame은 2차원 표다.
  • 명시적 인덱스와 암묵적 위치를 구분한다.
  • loc는 라벨 기준, iloc는 위치 기준이다.
  • 마스킹으로 조건 필터링을 수행한다.

객관식 포인트

loc 슬라이싱은 끝 라벨을 포함하고, iloc는 Python 슬라이싱처럼 끝 위치를 포함하지 않는다.

대표 코드

ser = pd.Series(['A', 'B'], index=[1, 3])
df['CO(GT)']
df.loc[0:3, 'CO(GT)']
df.iloc[0:3, 1:4]
df[df['CO(GT)'] >= 2.0]
예상 서술형: Pandas의 인덱스는 단순 행 번호가 아니라 데이터를 식별하는 라벨이다. loc는 라벨을 기준으로 선택하고 iloc는 정수 위치를 기준으로 선택한다. 숫자 인덱스가 있을 때 두 방식의 결과가 달라질 수 있으므로 분석에서 명확히 구분해야 한다.

5장: 데이터 결합과 EDA

실습 06, 07

핵심 개념

  • concat은 축 방향 연결이다.
  • merge는 공통 키 기준 결합이다.
  • inner/left/outer join 결과를 직접 그릴 수 있어야 한다.
  • EDA는 분석 전 데이터 품질을 점검한다.

왜 중요한가

실제 데이터는 여러 테이블로 나뉘어 있고 결측치나 이상치가 섞여 있다. 결합 방식과 EDA는 분석 결과의 신뢰도를 결정한다.

대표 코드

pd.concat([df1, df2])
pd.merge(users, logs, on='UserID', how='left')
df.info()
df.describe()
df.isna().sum()
sns.heatmap(df.corr())
예상 서술형: Left join은 왼쪽 테이블의 모든 행을 유지하면서 오른쪽 테이블의 매칭 값을 붙인다. 매칭되지 않은 값은 NaN으로 나타난다. 이 NaN은 단순 오류가 아니라 미활동 사용자, 누락 로그, 매칭 실패 같은 데이터 상태를 해석하는 단서가 된다.

대표 코드

res = requests.get(url, headers=headers)
soup = BeautifulSoup(res.text, 'html.parser')
soup.select('.news-title')
res = requests.get(api_url, params=params)
data = res.json()
예상 서술형: API는 제공자가 정한 URL과 파라미터를 이용해 JSON 같은 구조화 데이터를 받는 방식이고, 웹스크래핑은 HTML에서 직접 필요한 태그를 찾아 추출하는 방식이다. API는 자동화와 안정성에 유리하지만 rate limit을 고려해야 하고, 스크래핑은 API가 없을 때 유용하지만 HTML 구조 변경에 취약하다.

7장: 시계열 데이터

실습 10, 11

핵심 개념

  • 문자열 날짜는 datetime으로 변환해야 시간 연산이 가능하다.
  • 시계열 인덱스는 시간 기준 선택과 집계에 중요하다.
  • resampling은 시간 단위를 바꿔 집계한다.
  • rolling은 이동 창으로 통계를 계산한다.

주관식 포인트

strftime은 datetime을 문자열로 출력하고, pd.to_datetime은 문자열을 datetime으로 바꾼다.

대표 코드

pd.to_datetime(df['date'])
df = df.set_index('date')
date.strftime('%a')
df.resample('D').mean()
df.rolling(window=3).mean()
df.shift(1)
예상 서술형: Resampling은 시계열 데이터의 시간 단위를 바꾸어 집계하는 작업이다. Rolling은 일정한 크기의 이동 창을 사용해 이동 평균 같은 값을 계산한다. Resampling은 시간 해상도 조정에, rolling은 추세 파악과 노이즈 완화에 유용하다.

8장: 결측치 처리와 대치

실습 12, 13

핵심 개념

  • None과 NaN은 결측 표현이다.
  • isnull, notnull로 결측 여부를 확인한다.
  • 결측치는 제거하거나 대치할 수 있다.
  • 대치 방법은 MAE 같은 지표로 비교할 수 있다.

헷갈리는 포인트

결측치를 제거하면 데이터 손실이 생기고, 대치하면 분포가 왜곡될 수 있다. 결측 원인과 분석 목적을 먼저 봐야 한다.

대표 코드

df.isnull().sum()
df.dropna()
df.fillna(df.mean(numeric_only=True))
df.fillna(method='ffill')
mean_absolute_error(y_true, y_pred)
예상 서술형: 결측치 제거는 구현이 간단하지만 데이터 수가 줄어들고 편향이 생길 수 있다. 결측치 대치는 데이터 크기를 유지하지만 실제 값을 정확히 복원하는 것은 아니므로 분포나 추세가 왜곡될 수 있다. 시계열에서는 이전 값이 다음 값과 관련될 수 있어 forward fill이 의미 있을 수 있다.

9장: 이상치 탐지

실습 14

핵심 개념

  • 이상치는 정상 패턴에서 크게 벗어난 값이다.
  • IQR은 Q3와 Q1의 차이다.
  • IQR 기준은 Q1 - 1.5*IQR, Q3 + 1.5*IQR이다.
  • Z-score는 평균에서 표준편차 몇 배 떨어졌는지 본다.

왜 중요한가

이상치는 평균, 분산, 상관관계, 모델 학습 결과를 왜곡할 수 있다. 하지만 실제 이상 신호일 수도 있으므로 제거 전 의미 해석이 필요하다.

대표 코드

q1 = df['x'].quantile(0.25)
q3 = df['x'].quantile(0.75)
iqr = q3 - q1
out = df[(df['x'] < q1 - 1.5*iqr) | (df['x'] > q3 + 1.5*iqr)]
z = (x - x.mean()) / x.std()
예상 서술형: IQR 방식은 사분위수를 기준으로 이상치를 판단한다. Q1보다 1.5*IQR만큼 더 작거나 Q3보다 1.5*IQR만큼 더 큰 값을 이상치 후보로 본다. 평균과 표준편차보다 극단값의 영향을 덜 받기 때문에 왜도나 극단값이 있는 데이터에서도 유용하다.

10장: 특징 추출 및 변환

StandardScaler().fit_transform(X)
예상 서술형: 특징 추출과 변환은 원천 데이터를 분석이나 모델 입력에 적합한 형태로 바꾸는 과정이다. 원핫인코딩은 범주형 변수를 숫자 컬럼으로 바꾸고, 정규화는 수치형 변수들의 스케일 차이를 줄인다. 이를 통해 분석 결과의 비교 가능성과 모델 입력 품질을 높일 수 있다.

4. 서술형 답안 모음

서술형은 정의, 원리, 예시, 데이터 엔지니어링 관점 4문장으로 쓰면 안정적입니다.

브로드캐스팅

브로드캐스팅은 shape이 다른 NumPy 배열끼리 연산할 수 있게 하는 규칙이다. 오른쪽 차원부터 비교하여 차원이 같거나 한쪽이 1이면 연산 가능하다. 예를 들어 여러 센서값에 같은 보정값을 더할 수 있다. 데이터 엔지니어링 관점에서는 반복문 없이 대량 데이터를 빠르게 처리할 수 있어 중요하다.

Left Join의 NaN

Left join은 왼쪽 테이블을 기준으로 모든 행을 유지하는 결합 방식이다. 오른쪽 테이블에 매칭되는 키가 없으면 해당 값은 NaN이 된다. 예를 들어 회원 테이블과 시청 로그를 결합하면 시청 기록이 없는 회원도 남는다. 이 NaN은 미활동 사용자나 누락 로그를 발견하는 단서가 될 수 있다.

결측치 대치

결측치 대치는 빈 값을 평균, 중앙값, 이전값 등으로 채우는 처리다. 데이터 수를 유지할 수 있지만 실제 분포를 왜곡할 수 있다. 시계열에서는 이전 값이 다음 값과 관련될 수 있어 forward fill이 유용할 수 있다. 데이터 엔지니어링 관점에서는 결측 원인을 해석한 뒤 대치 방식을 선택해야 한다.

특징 변환

특징 변환은 원천 데이터를 분석이나 모델 입력에 적합하게 바꾸는 과정이다. 범주형 데이터는 원핫인코딩으로, 스케일이 다른 수치형 데이터는 정규화로 처리할 수 있다. 예를 들어 등급 컬럼은 더미 변수로 바꾸고 센서값은 0~1 범위로 맞출 수 있다. 이는 모델이 데이터를 더 안정적으로 학습하도록 돕는다.
