2장. NumPy 배열 기초, 실습 01

import numpy as np

import numpy as np

NumPy를 np라는 짧은 이름으로 불러온다.
배열 생성, 수치 계산, 난수 생성, 집계 연산을 할 때 기본으로 사용한다.

np.array()

my_lst = [1, 2, 3, 4, 5]
my_arr = np.array(my_lst)

Python list를 NumPy 배열인 ndarray로 바꾼다.
NumPy 배열은 리스트와 달리 원소 단위 연산이 가능하다.

prices = [20, 40, 35]
prices_arr = np.array(prices)
prices_arr - 5

결과:

array([15, 35, 30])

시험 포인트:

  • list는 prices - 5처럼 직접 계산할 수 없다.
  • NumPy 배열은 모든 원소에 한 번에 연산을 적용한다.

배열 인덱싱

test_2 = np.array([79, 100, 86, 93, 91])
test_2[3]

위치 번호로 값 하나를 가져온다. Python과 NumPy는 0번부터 시작한다.
test_2[3]은 네 번째 값이다.

배열 슬라이싱

arr = np.arange(10)
arr[3:7]
arr[:5]
arr[5:]
arr[::3]
arr[2:8:2]

뜻:

코드 의미
arr[3:7] 3번부터 7번 전까지
arr[:5] 처음부터 5번 전까지
arr[5:] 5번부터 끝까지
arr[::3] 처음부터 끝까지 3칸씩
arr[2:8:2] 2번부터 8번 전까지 2칸씩

시험 포인트:

start 포함, stop 미포함, step 간격

2차원 배열 인덱싱

student_scores = np.array([test_1, test_2, test_3_fixed])
student_scores[2, 0]

[행, 열] 순서로 값을 가져온다.
student_scores[2, 0]은 2번 행, 0번 열이다.

불리언 마스크

a = np.array([1, 20, 4, 6, 28, 88, 7, 12])
mask = a >= 10
selected = a[a >= 10]

조건을 만족하는 값만 선택한다.

결과:

array([20, 28, 88, 12])

조건을 여러 개 결합할 때:

a[(a > 10) & (a < 30)]
a[(a > 6) | (a < 4)]

시험 포인트:

  • NumPy 배열 조건 결합은 and, or가 아니라 &, |를 쓴다.
  • 각 조건은 괄호로 감싼다.

배열 속성

arr.ndim
arr.shape
arr.size
arr.dtype
arr.itemsize
arr.nbytes
코드 의미
ndim 차원 수
shape 배열 모양
size 전체 원소 수
dtype 원소 자료형
itemsize 원소 1개의 메모리 크기
nbytes 배열 전체 메모리 크기

view와 copy

arr_sub = arr[:2, :2]
arr_sub[0, 0] = 99

NumPy 슬라이싱은 원본 배열의 view가 될 수 있다.
따라서 arr_sub를 바꾸면 원본 arr도 바뀔 수 있다.

원본을 바꾸고 싶지 않으면:

arr_sub = arr[:2, :2].copy()

시험 포인트:

view = 원본 공유
copy = 별도 복사본

reshape()

x = np.arange(10)
x_reshaped = x.reshape(2, 5)

배열의 모양을 바꾼다.
원소 수가 맞아야 한다.

10개 원소 -> 2 x 5 가능
10개 원소 -> 3 x 4 불가능

np.newaxis

arr = np.arange(3)
arr_new = arr[np.newaxis, :]

차원을 하나 추가한다.

(3,) -> (1, 3)

배열 연결과 분할

np.concatenate([arr_1, arr_2, arr_3])
np.vstack([arr_1, arr_2, arr_3])
np.hstack([arr_1, arr_2, arr_3])
np.split(arr, [3, 5])
코드 의미
concatenate 배열을 이어 붙임
vstack 세로 방향 연결
hstack 가로 방향 연결
split 지정 위치에서 분할

3장. NumPy UFunc와 고급 기능, 실습 02-03

난수 고정과 생성

np.random.seed(3)
arr = np.random.rand(1000000)

seed는 난수 재현성을 위한 기준값이다.
rand(1000000)은 0 이상 1 미만의 실수 난수 100만 개를 만든다.

np.random.randint(10, size=5)

0 이상 10 미만의 정수 난수 5개를 만든다.

UFunc 산술 연산

x = np.arange(4)
x + 5
np.add(x, 5)
x ** 2
np.power(x, 2)

기호 연산과 함수 연산은 같은 결과를 낸다.

기호 UFunc
x + 5 np.add(x, 5)
x - 5 np.subtract(x, 5)
x * 2 np.multiply(x, 2)
x / 2 np.divide(x, 2)
x ** 2 np.power(x, 2)

시험 포인트:

  • 평소에는 x + 5가 편하다.
  • UFunc 함수형 표현은 reduce, accumulate 같은 확장 기능을 이해할 때 중요하다.

np.linspace()

np.linspace(0, 100, 5)

0부터 100까지 포함해서 총 5개의 값을 균일하게 만든다.

결과:

array([0., 25., 50., 75., 100.])

비교:

함수 세 번째 인자 끝값 포함
np.arange(start, stop, step) 간격 미포함
np.linspace(start, stop, num) 개수 기본 포함

reduce()와 accumulate()

x = np.arange(1, 5)
np.add.reduce(x)
np.add.accumulate(x)
np.multiply.reduce(x)
np.multiply.accumulate(x)

결과:

np.add.reduce(x)          # 10
np.add.accumulate(x)      # [1, 3, 6, 10]
np.multiply.reduce(x)     # 24
np.multiply.accumulate(x) # [1, 2, 6, 24]

주의:

np.prod.accumulate(x)

이 코드는 안 된다. np.prod는 일반 함수이고, accumulate는 UFunc인 np.multiply에 붙인다.

누적 곱은 다음 둘 중 하나를 쓴다.

np.multiply.accumulate(x)
np.cumprod(x)

집계 함수

np.sum(arr)
np.max(arr)
np.min(arr)
np.mean(arr)
np.median(arr)
np.percentile(arr, 90)
np.var(arr)
np.std(arr)
np.argmax(arr)
np.argmin(arr)
np.any(arr > 1)
np.all(arr > 0)
코드 의미
sum 합계
mean 평균
std 표준편차
argmax 최댓값 위치
argmin 최솟값 위치
any 하나라도 True인지
all 모두 True인지

axis

arr = np.array([[1, 2, 3],
                [4, 5, 6]])

np.sum(arr, axis=0)
np.sum(arr, axis=1)

결과:

np.sum(arr, axis=0) # [5, 7, 9]
np.sum(arr, axis=1) # [6, 15]

시험 포인트:

axis=0 -> 행 축을 줄여 열별 결과
axis=1 -> 열 축을 줄여 행별 결과

브로드캐스팅

a = np.ones((3, 3))
b = np.arange(3)
a + b

a는 3행 3열의 1 배열이다.
b는 [0, 1, 2]이다.
b가 각 행에 반복 적용되어 결과는 다음과 같다.

array([[1., 2., 3.],
       [1., 2., 3.],
       [1., 2., 3.]])

양쪽 브로드캐스팅

a = np.arange(3).reshape((3, 1))
b = np.arange(3)
a + b

a.shape = (3, 1)이고 b.shape = (3,)이다.
b는 (1, 3)처럼 취급되어 결과 shape은 (3, 3)이 된다.

결과:

array([[0, 1, 2],
       [1, 2, 3],
       [2, 3, 4]])

팬시 인덱싱

row = [0, 1, 2]
col = [2, 1, 4]
x[row, col]

같은 위치끼리 짝지어 선택한다.

x[0, 2], x[1, 1], x[2, 4]

팬시 인덱싱 + 브로드캐스팅

row = np.array([0, 1, 2])
col = np.array([2, 1, 4])
x[row[:, np.newaxis], col]

row[:, np.newaxis]는 row를 세로 모양 (3, 1)로 만든다.
col은 (3,), 즉 (1, 3)처럼 취급된다.
결과적으로 모든 행과 열 조합을 가져와 (3, 3) 결과를 만든다.

Pandas 불러오기

    'name': ['Kim', 'Lee', 'Park'],

df.index
df.columns
df.values
코드 의미

하나의 컬럼을 선택하면 Series가 되고, 여러 컬럼을 선택하면 DataFrame이 된다.

조건을 만족하는 행만 선택한다.

파생 컬럼 생성

df['CO_Double'] = df['CO(GT)'] * 2

기존 컬럼을 이용해 새로운 컬럼을 만든다.

8장. 결측치 처리와 대치, 실습 12-13

None과 NaN

arr1 = np.array([1, 2, None, 4])
arr3 = np.array([1, np.nan, 3, 4])

None은 Python 객체이고, NaN은 숫자형 결측값이다.
NumPy/Pandas 연산에서는 보통 NaN이 더 자연스럽다.

결측치 확인

df.isnull()
df.notnull()
df.isnull().sum()
코드 의미
isnull() 결측이면 True
notnull() 결측이 아니면 True
isnull().sum() 컬럼별 결측 개수

결측치 제거

df.dropna()
df.dropna(axis=1)
코드 의미
dropna() 결측치가 있는 행 제거
dropna(axis=1) 결측치가 있는 열 제거

결측치 대치

df.fillna(0)
df.fillna(df.mean(numeric_only=True))
df.fillna(method='ffill')
df.fillna(method='bfill')
코드 의미
fillna(0) 0으로 대치
fillna(mean) 평균으로 대치
ffill 이전 값으로 대치
bfill 다음 값으로 대치

의도적 결측치 생성

np.random.seed(42)
mask = np.random.rand(len(df)) < 0.3
df_missing = df.copy()
df_missing.loc[mask, target_col] = np.nan

전체 데이터 중 약 30% 위치를 결측치로 만든다.
대치 방법을 비교하기 위한 실험에 사용한다.

MAE 평가

from sklearn.metrics import mean_absolute_error
mae = mean_absolute_error(y_true, y_pred)

실제 값과 대치 값의 평균 절대 오차를 계산한다.
값이 작을수록 대치가 원본에 가깝다.

시험 포인트:

  • 결측치 제거는 간단하지만 데이터 손실이 있다.
  • 결측치 대치는 데이터 수를 유지하지만 분포를 왜곡할 수 있다.

9장. 이상치 탐지, 실습 14

선형 보간

co = df['CO(GT)'].copy()
co.interpolate(method='linear', inplace=True)

결측값을 앞뒤 값의 선형 흐름으로 채운다.
시계열 센서 데이터에서 자주 사용한다.

IQR 기반 이상치 탐지

q1 = co.quantile(0.25)
q3 = co.quantile(0.75)
iqr = q3 - q1

lower = q1 - 1.5 * iqr
upper = q3 + 1.5 * iqr

outliers = co[(co < lower) | (co > upper)]

IQR은 데이터의 중간 50% 범위다.
일반적으로 lower보다 작거나 upper보다 큰 값을 이상치 후보로 본다.

Z-score 기반 이상치 탐지

z = (co - co.mean()) / co.std()
outliers = co[np.abs(z) > 3]

평균에서 표준편차 몇 배만큼 떨어졌는지 계산한다.
보통 절댓값이 3보다 크면 이상치 후보로 본다.

시험 포인트:

방법 기준
IQR 사분위수 기반
Z-score 평균과 표준편차 기반

정규화나 구간화 전에 데이터 범위를 확인한다.

연속형 값을 몇 개의 구간으로 나눈다.
예: 낮음, 보통, 높음 같은 범주로 변환.

개념 차이 말하기 정리

시험에서 객관식은 개념 차이를 고르는 형태로, 주관식/서술형은 그 차이를 말로 설명하는 형태로 나올 수 있다. 아래 문장을 그대로 말할 수 있으면 안정적이다.

Python list vs NumPy array

구분 Python list NumPy array
성격 일반적인 값의 묶음 수치 계산에 최적화된 배열
연산 원소 단위 산술 연산이 바로 어렵다 원소 단위 연산이 가능하다
예시 prices - 5 불가능 prices_arr - 5 가능

말하기:

Python list는 일반적인 값의 묶음이고, NumPy array는 수치 계산에 최적화된 배열이다.
NumPy array는 배열 전체에 같은 연산을 한 번에 적용할 수 있어 대량 데이터 처리에 유리하다.

view vs copy

구분 view copy
의미 원본 데이터를 공유 원본과 별도의 복사본 생성
원본 변경 바뀔 수 있음 바뀌지 않음
코드 arr[:2, :2] arr[:2, :2].copy()

말하기:

view는 원본 배열의 메모리를 공유하는 결과이고, copy는 별도의 복사본이다.
view를 수정하면 원본도 바뀔 수 있으므로 원본 변경을 피하려면 copy()를 사용해야 한다.

arange vs linspace

구분 np.arange() np.linspace()
세 번째 인자 간격 step 개수 num
끝값 stop 미포함 기본적으로 stop 포함
예시 np.arange(0, 100, 5) np.linspace(0, 100, 5)

말하기:

arange는 시작값부터 끝값 전까지 일정 간격으로 값을 만든다.
linspace는 시작값부터 끝값까지 포함해서 지정한 개수만큼 균일한 간격의 값을 만든다.

axis=0 vs axis=1

구분 의미 결과 관점
axis=0 행 축을 줄임 열별 결과
axis=1 열 축을 줄임 행별 결과

말하기:

axis=0은 행 방향으로 내려가며 집계하므로 열별 결과를 만든다.
axis=1은 열 방향으로 가로로 집계하므로 행별 결과를 만든다.

loc vs iloc

구분 loc iloc
기준 라벨, 명시적 인덱스 정수 위치, 암묵적 인덱스
슬라이싱 끝 라벨 포함 끝 위치 미포함
예시 ser.loc[1:3] ser.iloc[1:3]

말하기:

loc는 데이터에 붙은 라벨을 기준으로 선택하고, iloc는 실제 위치 번호를 기준으로 선택한다.
숫자 인덱스가 있을 때 같은 숫자를 넣어도 loc와 iloc의 결과가 달라질 수 있다.

Series vs DataFrame

구분 Series DataFrame
차원 1차원 2차원
구조 인덱스 + 값 인덱스 + 컬럼 + 값
예시 한 컬럼 선택 결과 여러 컬럼이 있는 표

말하기:

Series는 1차원 라벨 배열이고, DataFrame은 행과 열을 가진 2차원 표 형태 객체다.
DataFrame에서 하나의 컬럼을 선택하면 보통 Series가 되고, 여러 컬럼을 선택하면 DataFrame이 된다.

concat vs merge

구분 concat merge
기준 축 방향으로 이어 붙임 공통 키 기준 결합
상황 같은 구조의 데이터 연결 서로 다른 테이블 연결
예시 월별 데이터 쌓기 회원 정보와 로그 결합

말하기:

concat은 여러 데이터 객체를 행 또는 열 방향으로 단순 연결하는 방식이다.
merge는 공통 키를 기준으로 관계형 데이터베이스의 join처럼 테이블을 결합하는 방식이다.

inner join vs left join vs outer join

구분 의미
inner join 양쪽에 모두 있는 키만 남김
left join 왼쪽 테이블의 행을 모두 보존
outer join 양쪽 테이블의 키를 모두 보존

말하기:

inner join은 양쪽 테이블에 공통으로 존재하는 키만 남긴다.
left join은 왼쪽 테이블을 기준으로 보존하고, 매칭되지 않는 오른쪽 값은 NaN이 된다.
outer join은 양쪽 테이블의 모든 키를 살리고 없는 값은 NaN으로 채운다.

웹스크래핑 vs API

구분 웹스크래핑 API
대상 HTML 문서 구조화된 데이터 인터페이스
주요 코드 BeautifulSoup, select() requests.get(), params, json()
주의점 HTML 구조 변경에 취약 rate limit, 인증, 파라미터

말하기:

웹스크래핑은 HTML 페이지에서 원하는 태그를 찾아 데이터를 추출하는 방식이다.
API는 서비스가 제공하는 정해진 URL과 파라미터를 통해 JSON 같은 구조화 데이터를 요청하는 방식이다.

문자열 날짜 vs datetime

구분 문자열 날짜 datetime
성격 텍스트 시간 연산 가능한 객체
가능 작업 단순 표시 정렬, 필터링, resampling
변환 코드 원본 문자열 pd.to_datetime()

말하기:

문자열 날짜는 단순 텍스트라 시간 연산에 한계가 있다.
datetime으로 변환하면 날짜 기준 정렬, 기간 필터링, 시계열 집계가 가능해진다.

resampling vs rolling

구분 resampling rolling
목적 시간 단위 변경 이동 창 통계
예시 일별 평균, 월별 합계 3일 이동 평균
코드 df.resample('D').mean() df.rolling(3).mean()

말하기:

resampling은 시계열 데이터의 시간 단위를 바꿔 집계하는 작업이다.
rolling은 일정한 크기의 이동 창을 사용해 이동 평균 같은 통계를 계산하는 작업이다.

결측치 vs 이상치

구분 결측치 이상치
의미 값이 없음 값은 있지만 비정상적으로 벗어남
예시 NaN, None 매우 큰 센서값
처리 제거, 대치 탐지, 검토, 제거/유지 판단

말하기:

결측치는 값이 없는 상태이고, 이상치는 값은 존재하지만 정상 범위에서 크게 벗어난 값이다.
결측치는 제거나 대치가 필요하고, 이상치는 오류인지 실제 이상 신호인지 해석이 필요하다.

결측치 제거 vs 결측치 대치

구분 제거 대치
의미 결측 행/열 삭제 빈 값을 다른 값으로 채움
장점 단순하고 잘못된 값을 넣지 않음 데이터 수 유지
단점 데이터 손실 분포 왜곡 가능

말하기:

결측치 제거는 간단하지만 데이터 손실과 편향이 생길 수 있다.
결측치 대치는 데이터 수를 유지하지만 실제 값을 완벽히 복원하는 것은 아니므로 분포 왜곡에 주의해야 한다.

IQR vs Z-score

구분 IQR Z-score
기준 사분위수 평균과 표준편차
이상치 기준 Q1 - 1.5*IQR, Q3 + 1.5*IQR 보통 abs(z) > 3
특징 극단값 영향이 비교적 작음 정규분포에 가까울 때 이해하기 쉬움

말하기:

IQR 방식은 Q1과 Q3 사이의 범위를 기준으로 이상치를 판단한다.
Z-score 방식은 값이 평균에서 표준편차 몇 배만큼 떨어져 있는지를 기준으로 이상치를 판단한다.

one-hot encoding vs normalization

구분 one-hot encoding normalization
대상 범주형 데이터 수치형 데이터
목적 숫자 컬럼으로 변환 값의 범위 조정
예시 요일, 등급, 카테고리 센서값, 농도, 가격

말하기:

원핫인코딩은 범주형 데이터를 0과 1로 된 여러 숫자 컬럼으로 바꾸는 방법이다.
정규화는 수치형 변수의 스케일을 맞춰 서로 다른 단위의 값을 비교하거나 모델에 넣기 쉽게 만드는 방법이다.
